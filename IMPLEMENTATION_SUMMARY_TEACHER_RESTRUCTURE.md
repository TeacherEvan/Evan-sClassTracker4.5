## 🔧 Technical Implementation

### 1. Auto-Approval System

**How it works**:

```typescript
// Teacher booking provider class
const status = isTeacher && hasProvider ? "approved" : "pending";
const approvalSource = isTeacher && hasProvider ? "auto_provider" : undefined;
```

**Security checks**:

- Teachers: Can only book for THEIR school OR THEIR providers
- Moderators: STRICTLY school-scoped, CANNOT access providers
- Admins: God mode (no restrictions)

**Audit trail**:

- Action logged as "book_class" (not "request_class")
- approvalSource field tracks approval method

### 2. Auto-Provider Creation

**Trigger**: When teacher creates student with self-reference as guardian

**Process**:

```typescript
// Get or create provider
const { providerId, isNew } = await getOrCreateTeacherProvider({ teacherId });

// Use providerId for student/class creation
```

**Provider naming**: "{username}'sPVTclass" / "{username}ของชั้นเรียนส่วนตัว"

**Duplicate prevention**: Case-insensitive check for existing PVTclass providers

### 3. Duplicate Detection

**Comparison algorithm**:

```typescript
// Compare 7 fields
firstName (case-insensitive)
lastName (case-insensitive)
grade (exact)
dateOfBirth (exact)
guardianPhone (exact)
area (exact)
schoolId (exact)

// Flag if 4+ matches
```

**Workflow**:

1. Student created
2. `detectDuplicates()` called with new studentId
3. If 4+ matches found → Insert into watchlist
4. Frontend shows modal (optional - not yet implemented)
5. Admin reviews in dashboard

**Watchlist statuses**:

- `pending`: Awaiting admin review
- `reviewed`: Admin has reviewed (not merged)
- `merged`: Students have been merged
- `dismissed`: Admin dismissed as non-duplicate

## 🔐 Security Boundaries

### Teacher Permissions

- ✅ Book classes for THEIR school students
- ✅ Book classes for THEIR provider students
- ✅ Auto-approved for provider classes
- ❌ Cannot access other teachers' providers
- ❌ Cannot book for other schools

### Moderator Permissions

- ✅ Book classes for THEIR school only
- ✅ Auto-approved for school classes
- ❌ CANNOT access providers (strict boundary)
- ❌ CANNOT book provider classes
- ❌ Cannot bypass school boundaries

### Admin Permissions

- ✅ God mode - full access to all schools/providers
- ✅ Manage duplicate watchlist
- ✅ Merge/dismiss duplicates

```typescript
await ctx.runMutation(api.classes.book, {
  teacherId: "...",
  providerId: "...", // Teacher's own provider

  scheduledDate: Date.now(),
  bookedByUserId: "...",
  // ... other fields
});

// Result: status="approved", approvalSource="auto_provider"
```

### Auto-Provider Creation

**Get or create teacher provider**:

```typescript
const result = await ctx.runMutation(api.providers.getOrCreateTeacherProvider, {
  teacherId: "..."
});

// Returns:
{
  providerId: Id<"providers">,
  isNew: boolean // true if newly created
}
```

### Duplicate Detection

**Detect duplicates after student creation**:

```typescript
const result = await ctx.runMutation(api.duplicateDetection.detectDuplicates, {
  studentId: "...",
  userId: "..."
});

// Returns:
{
  hasDuplicates: boolean,
  duplicates: [
    {
      studentId: Id<"students">,
      matches: number, // Count of matching fields
      details: {
        firstName: boolean,
        lastName: boolean,
        grade: boolean,
        // ... other fields
      }
    }
  ],
  message: string
}
```

### Admin Watchlist Operations

**List watchlist entries**:

```typescript
const entries = await ctx.runQuery(api.duplicateDetection.listWatchlist, {
  userId: adminId,
  status: "pending" // optional: "pending" | "reviewed" | "merged" | "dismissed"
});
```

**Get watchlist statistics**:

```typescript
const stats = await ctx.runQuery(api.duplicateDetection.getWatchlistStats, {
  userId: adminId
});

// Returns: { total, pending, reviewed, merged, dismissed }
```

**Dismiss duplicate**:

```typescript
await ctx.runMutation(api.duplicateDetection.dismissDuplicate, {
  entryId: "...",
  userId: adminId,
  notes: "Reason for dismissal",
  notesTh: "เหตุผลในการปิด"
});
```

**Merge duplicate students**:

```typescript
await ctx.runMutation(api.duplicateDetection.mergeDuplicateStudents, {
  entryId: "...",
  keepStudentId: "...", // Student to keep
  deleteStudentIds: ["...", "..."], // Students to merge and delete
  userId: adminId,
  notes: "Merge reason",
  notesTh: "เหตุผลในการรวม"
});

// Process:
// 1. Reassign all classes from deleted students to kept student
// 2. Delete duplicate students
// 3. Update watchlist entry status to "merged"
```
