## 📋 Archive Policy

**Documents belong in Deep/ when:**

- ✅ Implementation plans that haven't been executed yet
- ✅ Research findings that informed past decisions
- ✅ Audit reports older than 30 days
- ✅ Completion summaries for finished phases
- ✅ Documentation consolidation reports

**Documents should stay in docs/ when:**

- ❌ Active reference guides (CI/CD, Testing, Deployment)
- ❌ Architecture documentation
- ❌ System overview and features
- ❌ Security reviews (current state)
- ❌ Quick reference cards
