# Help Window - Quick Start Guide

## What is it?

The Help Window is an interactive guide that helps users learn how to use the Class Tracker system. It's like having a built-in manual that's always available!

## Where to find it?

Look for the **green "Help" button** in the top-right corner of the screen after you login:

```
┌─────────────────────────────────────────────────┐
│  Class Tracker                                  │
│  Welcome, John · Teacher                        │
│                                                 │
│             [🌐] [🟢 Help] [📞] [⚙️] [🚪]       │
│                     ↑                           │
│                  Click here!                    │
└─────────────────────────────────────────────────┘
```

## How to use it?

### Step 1: Open Help

Click the green **"Help"** button

### Step 2: Browse Categories

You'll see organized categories of features:

- 📅 Class Booking
- 💬 Messages & Communication
- 📊 Reports & Analytics
- ⚙️ Management & Administration
- ✨ Advanced Features

### Step 3: Expand a Category

Click on any category header to see the features inside

### Step 4: View Feature Details

Click on any feature to see:

- What it does
- Step-by-step instructions
- Helpful tips

### Step 5: Try it

Close the help window and try using the feature you learned about!

## Example Use Cases

### "I want to book a class"

1. Click **Help** button
2. Expand **"Class Booking"** category
3. Click **"Book a Class"** feature
4. Read the 5-step instructions
5. Close help and book your class!

### "How do I send a message?"

1. Click **Help** button
2. Expand **"Messages & Communication"**
3. Click **"Send Messages"**
4. Follow the steps shown
5. Go to Messages tab and send!

### "I need to approve a booking (Moderator)"

1. Click **Help** button
2. Expand **"Class Booking"**
3. Click **"Approve Class Bookings"**
4. Learn the approval workflow
5. Go handle those pending requests!

## Role-Based Help

The help system is smart! It only shows you features you can actually use:

### If you're a **Teacher**

- You'll see features like booking classes, viewing calendar, sending messages
- You won't see moderator-only features like analytics

### If you're a **Moderator (Boss)**

- You'll see everything teachers see
- Plus: Analytics, approving bookings, managing students

### If you're an **Admin (Evan)**

- You'll see everything!
- Including: User management, school management, system admin features

## FAQ

**Q: Will the help window work offline?**
A: Yes! The help content is built into the app, so it works even without internet.

**Q: Can I search for specific topics?**
A: Currently, browse by category. Search functionality may be added in a future update!

**Q: How often is help content updated?**
A: Help content is updated with each app release. Check the app version in settings.

**Q: Can I bookmark help articles?**
A: Not yet, but this is a great idea for a future enhancement!

**Q: Is there a printable version?**
A: You can copy text from the help window to create your own notes or print them.
