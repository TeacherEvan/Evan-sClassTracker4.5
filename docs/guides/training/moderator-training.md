# Moderator Training Guide / คู่มือการฝึกอบรมผู้ดูแล

**Version**: 4.5.32
**Last Updated**: December 6, 2025
**Training Duration / ระยะเวลาการฝึกอบรม**: 1-2 hours / 1-2 ชั่วโมง
**Skill Level / ระดับทักษะ**: Beginner / ผู้เริ่มต้น

---

## Quick Start / เริ่มต้นอย่างรวดเร็ว

This guide provides step-by-step training for school moderators in both English and Thai.

คู่มือนี้ให้การฝึกอบรมแบบทีละขั้นตอนสำหรับผู้ดูแลโรงเรียนทั้งภาษาอังกฤษและไทย

**Prerequisites / ข้อกำหนดเบื้องต้น**:

- Moderator account credentials / ข้อมูลประจำตัวบัญชีผู้ดูแล
- Modern web browser / เบราว์เซอร์สมัยใหม่
- 1-2 hours training time / เวลาฝึกอบรม 1-2 ชั่วโมง

---

## Module 1: First Login / โมดูล 1: การเข้าสู่ระบบครั้งแรก

**Duration / ระยะเวลา**: 15 minutes / 15 นาที

### Logging In / การเข้าสู่ระบบ

**Steps / ขั้นตอน**:

1. Open application / เปิดแอปพลิเคชัน
2. Username: (provided by admin) / ชื่อผู้ใช้: (จัดเตรียมโดยผู้ดูแลระบบ)
3. Password: `Teacher{username}` / รหัสผ่าน: `Teacher{username}`
4. Change password / เปลี่ยนรหัสผ่าน
5. Dashboard appears / แดชบอร์ดปรากฏขึ้น

**Password Change / การเปลี่ยนรหัสผ่าน**:

- System forces change on first login / ระบบบังคับให้เปลี่ยนในการเข้าสู่ระบบครั้งแรก
- No requirements / ไม่มีข้อกำหนด
- Choose strong password / เลือกรหัสผ่านที่แข็งแกร่ง
- Remember it! / จำไว้!

## Module 2: Understanding Your Role / โมดูล 2: เข้าใจบทบาทของคุณ

**Duration / ระยะเวลา**: 15 minutes / 15 นาที

### What Moderators Can Do / ผู้ดูแลทำอะไรได้บ้าง

✅ **Allowed / อนุญาต**:

- Approve/reject classes at YOUR school / อนุมัติ/ปฏิเสธคลาสที่โรงเรียนของคุณ
- View classes at YOUR school / ดูคลาสที่โรงเรียนของคุณ
- View students at YOUR school / ดูนักเรียนที่โรงเรียนของคุณ
- Send messages to teachers / ส่งข้อความถึงครู
- View school analytics / ดูการวิเคราะห์โรงเรียน

❌ **Not Allowed / ไม่อนุญาต**:

- Access other schools' data / เข้าถึงข้อมูลโรงเรียนอื่น
- Create users or schools / สร้างผู้ใช้หรือโรงเรียน
- Change school assignment / เปลี่ยนการมอบหมายโรงเรียน
- Create providers / สร้างผู้ให้บริการ

### School Scoping / ขอบเขตโรงเรียน

**Important / สำคัญ**: You are assigned to ONE school only.

**สำคัญ**: คุณได้รับมอบหมายให้ดูแลโรงเรียนเดียวเท่านั้น

- School dropdown is LOCKED / ดรอปดาวน์โรงเรียนถูกล็อค
- Cannot change to other schools / ไม่สามารถเปลี่ยนไปยังโรงเรียนอื่น
- This is for security / นี่เพื่อความปลอดภัย

## Module 3: Class Approval Workflow / โมดูล 3: ขั้นตอนการอนุมัติคลาส

**Duration / ระยะเวลา**: 30 minutes / 30 นาที

### Class Statuses / สถานะคลาส

1. **Pending (Yellow / สีเหลือง)**: Waiting for your review / รอการตรวจสอบของคุณ
2. **Acknowledged (Blue / สีน้ำเงิน)**: You've seen it / คุณได้เห็นแล้ว
3. **Approved (Green / สีเขียว)**: Class confirmed / คลาสได้รับการยืนยัน
4. **Rejected (Red / สีแดง)**: Not approved / ไม่ได้รับการอนุมัติ

### Approving Classes / การอนุมัติคลาส

**Steps / ขั้นตอน**:

1. Navigate to Classes tab / ไปที่แท็บคลาส
2. Find pending class (yellow) / หาคลาสที่รอดำเนินการ (สีเหลือง)
3. Review details / ตรวจสอบรายละเอียด
   - Teacher name / ชื่อครู
   - Student name / ชื่อนักเรียน
   - Date and time / วันที่และเวลา
   - Class description / รายละเอียดคลาส
4. Click "Approve" / คลิก "อนุมัติ"
5. Teacher receives notification / ครูได้รับการแจ้งเตือน

**✅ Practice / ฝึกปฏิบัติ**: Approve a test class

### Rejecting Classes / การปฏิเสธคลาส

**Steps / ขั้นตอน**:

1. Find class to reject / หาคลาสที่จะปฏิเสธ
2. Click "Reject" / คลิก "ปฏิเสธ"
3. Provide reason / ให้เหตุผล
   - English reason (optional) / เหตุผลภาษาอังกฤษ (ไม่บังคับ)
   - Thai reason (optional) / เหตุผลภาษาไทย (ไม่บังคับ)
   - **Note / หมายเหตุ**: At least ONE language required / ต้องการอย่างน้อยหนึ่งภาษา
4. Confirm rejection / ยืนยันการปฏิเสธ
5. Teacher receives notification with reason / ครูได้รับการแจ้งเตือนพร้อมเหตุผล

**Best Practice / แนวทางที่ดี**: Always provide clear reason to help teachers.

**แนวทางที่ดี**: ระบุเหตุผลที่ชัดเจนเสมอเพื่อช่วยครู

### Acknowledging Classes / การรับทราบคลาส

**Optional Step / ขั้นตอนที่เป็นทางเลือก**:

- Click "Acknowledge" to show you've seen the booking / คลิก "รับทราบ" เพื่อแสดงว่าคุณได้เห็นการจอง
- Status changes to blue / สถานะเปลี่ยนเป็นสีน้ำเงิน
- Use when you need more time to decide / ใช้เมื่อคุณต้องการเวลามากขึ้นในการตัดสินใจ
- Later, approve or reject / ภายหลัง อนุมัติหรือปฏิเสธ

## Module 4: Using Filters / โมดูล 4: การใช้ตัวกรอง

**Duration / ระยะเวลา**: 15 minutes / 15 นาที

### Filter Chips / ชิปตัวกรอง

**Available Filters / ตัวกรองที่มี**:

1. **Status / สถานะ**: Pending, Acknowledged, Approved, Rejected
2. **Teacher / ครู**: Select specific teacher / เลือกครูที่เฉพาะเจาะจง
3. **Student / นักเรียน**: Select specific student / เลือกนักเรียนที่เฉพาะเจาะจง
4. **Date Range / ช่วงวันที่**: Start and end dates / วันที่เริ่มต้นและสิ้นสุด
5. **Grade / ระดับชั้น**: Filter by grade level / กรองตามระดับชั้น

**How to Use / วิธีใช้**:

1. Click filter chip / คลิกชิปตัวกรอง
2. Select criteria / เลือกเกณฑ์
3. Applied filters show as colored chips / ตัวกรองที่ใช้แสดงเป็นชิปสี
4. Click "Clear All" to reset / คลิก "ล้างทั้งหมด" เพื่อรีเซ็ต

**✅ Practice / ฝึกปฏิบัติ**: Filter classes by "Pending" status only

---

## Module 5: Analytics & Reports / โมดูล 5: การวิเคราะห์และรายงาน

**Duration / ระยะเวลา**: 20 minutes / 20 นาที

### School Analytics / การวิเคราะห์โรงเรียน

#### Navigate to Analytics tab / ไปที่แท็บการวิเคราะห์**

**Summary Cards / การ์ดสรุป**:

1. **Total Classes / คลาสทั้งหมด**: Number of classes at your school / จำนวนคลาสที่โรงเรียนของคุณ
2. **Attendance Rate / อัตราการเข้าเรียน**: % of attended classes / เปอร์เซ็นต์ของคลาสที่เข้าเรียน
3. **Active Students / นักเรียนที่ใช้งาน**: Students with classes / นักเรียนที่มีคลาส
4. **Avg Class Size / ขนาดคลาสเฉลี่ย**: Average students per class / นักเรียนเฉลี่ยต่อคลาส

### Student Performance Table / ตารางผลการเรียนของนักเรียน

**Shows / แสดง**:

- Student name / ชื่อนักเรียน
- Total classes / คลาสทั้งหมด
- Attended classes / คลาสที่เข้าเรียน
- Attendance rate / อัตราการเข้าเรียน
- Performance rating / การจัดอันดับผลการเรียน
  - 🟢 Excellent (≥90%) / ดีเยี่ยม
  - 🔵 Good (70-89%) / ดี
  - 🟡 Needs Improvement (<70%) / ต้องปรับปรุง

### Exporting Reports / การส่งออกรายงาน

**Steps / ขั้นตอน**:

1. Select date range / เลือกช่วงวันที่
2. Click "Export CSV" / คลิก "ส่งออก CSV"
3. File downloads / ไฟล์ดาวน์โหลด
4. Open in Excel / เปิดใน Excel

**✅ Practice / ฝึกปฏิบัติ**: Generate report for last 30 days / สร้างรายงานสำหรับ 30 วันที่แล้ว

## Module 6: Messaging Teachers / โมดูล 6: การส่งข้อความถึงครู

**Duration / ระยะเวลา**: 15 minutes / 15 นาที

### Sending Group Messages / การส่งข้อความกลุ่ม

**Steps / ขั้นตอน**:

1. Click "Send Group Message" in Startup Window / คลิก "ส่งข้อความกลุ่ม" ในหน้าต่างเริ่มต้น
2. Select teachers (checkboxes) / เลือกครู (กล่องกาเครื่องหมาย)
3. Write message in English / เขียนข้อความภาษาอังกฤษ
4. Write message in Thai / เขียนข้อความภาษาไทย
5. **Note / หมายเหตุ**: At least ONE language required / ต้องการอย่างน้อยหนึ่งภาษา
6. Click "Send" / คลิก "ส่ง"

### Individual Messages / ข้อความรายบุคคล

**Steps / ขั้นตอน**:

1. Navigate to Messages tab / ไปที่แท็บข้อความ
2. Click "New Message" / คลิก "ข้อความใหม่"
3. Select one teacher / เลือกครูหนึ่งคน
4. Write bilingual message / เขียนข้อความสองภาษา
5. Click "Send" / คลิก "ส่ง"

**✅ Practice / ฝึกปฏิบัติ**: Send test message to yourself

## Troubleshooting / การแก้ปัญหา

### Common Issues / ปัญหาที่พบบ่อย

**Issue 1**: Can't see any classes / ไม่เห็นคลาสใดๆ

**Solution / วิธีแก้**:

- Check filter settings / ตรวจสอบการตั้งค่าตัวกรอง
- Clear all filters / ล้างตัวกรองทั้งหมด
- Refresh page / รีเฟรชหน้า
- Contact admin if still not working / ติดต่อผู้ดูแลระบบหากยังไม่ทำงาน

**Issue 2**: School dropdown is not locked / ดรอปดาวน์โรงเรียนไม่ถูกล็อค

**Solution / วิธีแก้**:

- This is a bug / นี่เป็นข้อผิดพลาด
- Report to admin / รายงานให้ผู้ดูแลระบบ
- Backend still blocks cross-school access / แบ็กเอนด์ยังคงบล็อกการเข้าถึงข้ามโรงเรียน

**Issue 3**: Export not working / การส่งออกไม่ทำงาน

**Solution / วิธีแก้**:

- Check browser download settings / ตรวจสอบการตั้งค่าการดาวน์โหลดเบราว์เซอร์
- Allow downloads from site / อนุญาตการดาวน์โหลดจากไซต์
- Try different browser / ลองเบราว์เซอร์อื่น

## Best Practices / แนวทางปฏิบัติที่ดี

### Approval Speed / ความเร็วในการอนุมัติ

- Review classes within 24-48 hours / ตรวจสอบคลาสภายใน 24-48 ชั่วโมง
- Prioritize urgent classes / จัดลำดับความสำคัญคลาสเร่งด่วน
- Use acknowledge if you need time / ใช้การรับทราบหากคุณต้องการเวลา

### Communication / การสื่อสาร

- Provide clear rejection reasons / ระบุเหตุผลการปฏิเสธที่ชัดเจน
- Message teachers proactively / ส่งข้อความถึงครูเชิงรุก
- Use both languages when possible / ใช้ทั้งสองภาษาเมื่อเป็นไปได้

### Organization / การจัดองค์กร

- Check dashboard daily / ตรวจสอบแดชบอร์ดทุกวัน
- Use filters to stay organized / ใช้ตัวกรองเพื่อจัดระเบียบ
- Review weekly analytics / ตรวจสอบการวิเคราะห์รายสัปดาห์
