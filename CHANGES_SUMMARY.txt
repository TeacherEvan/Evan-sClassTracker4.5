ISSUE: Create "new student" features not everywhere similar
================================================================================

PROBLEM:
--------
1. The Grade field was redundant in student creation forms because the Class 
   field (K1, K2, K3) already provides the grade information.
2. Student creation forms were inconsistent across different components.
3. weekly-calendar.tsx was creating students with empty grade strings.

SOLUTION IMPLEMENTED:
--------------------
1. Removed the Grade input field from class-booking.tsx student creation form
2. Added Class dropdown to weekly-calendar.tsx for consistency
3. Implemented automatic grade derivation from class selection
4. Ensured all quick student creation forms follow the same pattern

CHANGES MADE:
-------------

- Removed: Grade input field from the form UI

- Updated: Form reset to exclude grade state

- Added: const [newStudentClass, setNewStudentClass] = useState("");

- Updated: Validation to require class field

Auto-Derivation Logic (added to both files):
---------------------------------------------
const gradeMap: Record<string, string> = {
  "K1": "Kindergarten 1",
  "K2": "Kindergarten 2",
  "K3": "Kindergarten 3",
};
const derivedGrade = gradeMap[newStudentClass] || newStudentClass;
