# 🎓 Teacher's Helper - User Guide

## Quick Start Guide

### 🎯 What is Teacher's Helper?

Teacher's Helper is a curated collection of educational resource links that provides quick access to popular teaching websites and tools. It's designed to save teachers time by keeping their favorite resources just one click away.

---

## 👥 For Teachers & Moderators

### Accessing Resources

1. **Login** to your account
2. **Click the "Teacher's Helper" tab** (📖 BookOpen icon) in the navigation bar
3. **Browse resource cards** showing popular educational sites
4. **Click any card** to open that resource in a new browser tab
5. **Switch language** (EN/TH) to see content in your preferred language

### What You'll See

- **Resource Cards**: Each card shows:
  - Category badge (e.g., "Worksheets & Games")
  - Resource name (e.g., "Education.com")
  - Brief description
  - Website URL preview
  
- **Mobile-Friendly**: Cards adapt to your screen size:
  - 1 column on phones
  - 2 columns on tablets
  - 3 columns on desktops

### Tips for Teachers

- 💡 All links open in new tabs so you don't lose your place
- 💡 Some resources may require free registration
- 💡 Bookmark your favorites in your browser
- 💡 Check back regularly - admin may add new resources!

---

## 👑 For Admin Users

### First-Time Setup

1. **Login as admin**
2. **Click "Teacher's Helper" tab**
3. **Click "Initialize Defaults" button** (green button, top right)
4. **Confirm** the dialog
5. **Success!** 5 popular resources are now available

### Managing Resources

#### Add New Resource

1. Click **"Add Resource"** button (blue, top right)
2. Fill in the form:
   - **Title (English)** * required
   - **Title (Thai)** * required
   - **URL** * required (must be valid http:// or https://)
   - **Category (English)** * required
   - **Category (Thai)** * required
   - **Description (English)** optional but recommended
   - **Description (Thai)** optional but recommended
3. Click **"Save"**

#### Edit Existing Resource

1. Click the **pencil icon** (✏️) on any resource
2. Modify fields as needed
3. Click **"Save"** to confirm or **"Cancel"** to abort

#### Hide/Show Resources

1. Click the **eye icon** (👁️) to toggle active/inactive
2. **Active** (eye open) = visible to teachers
3. **Inactive** (eye closed) = hidden from teachers, grayed out in admin view

#### Delete Resource

1. Click the **trash icon** (🗑️)
2. **Confirm** the deletion dialog
3. Resource is permanently removed

### Admin Interface Features

- **Status Badges**:
  - Green "Active" = Teachers can see it
  - Gray "Inactive" = Hidden from teachers
  
- **Category Badges**: Blue tags showing resource type

- **Real-time Updates**: Changes appear immediately for all users

- **Validation**:
  - URL format checking
  - Required field validation
  - Error messages for guidance

## ❓ Frequently Asked Questions

### For Teachers

**Q: Can I add my own resources?**  
A: No, only admins can add resources. Contact your admin if you have suggestions!

**Q: Why can't I see a resource that was there before?**  
A: Your admin may have temporarily hidden it. It might come back!

**Q: Do I need accounts on these websites?**  
A: Some resources require free registration. Check each site's requirements.

**Q: Can I access these resources offline?**  
A: No, Teacher's Helper links to online websites. You need internet access.

### For Admins

**Q: How many resources can I add?**  
A: Unlimited! Add as many as your teachers need.

**Q: What happens if I delete a resource?**  
A: It's permanently removed. Use "inactive" if you want to temporarily hide it.

**Q: Can I reorder the resources?**  
A: Currently, resources are ordered by creation order. Reordering feature may be added in the future.

**Q: What makes a good resource URL?**  
A: Use direct links to useful pages (not just homepages). For example:

- ✅ `https://www.education.com/worksheets/`
- ❌ `https://www.education.com/`

**Q: Can I edit the default resources?**  
A: Yes! You can edit or delete any resource, including the defaults.

## 💡 Best Practices

### For Admins

1. **Start with defaults**: Use "Initialize Defaults" before adding custom resources
2. **Quality over quantity**: Add only high-quality, trusted educational sites
3. **Use good descriptions**: Help teachers understand what each resource offers
4. **Keep URLs current**: Periodically check that links still work
5. **Use inactive instead of delete**: Temporarily hide resources you might want back
6. **Add bilingual content**: Always fill in both English and Thai fields
7. **Category consistently**: Use clear, consistent category names

### For Teachers

1. **Explore all resources**: Each has different strengths
2. **Bookmark favorites**: Use browser bookmarks for quick access
3. **Share feedback**: Tell your admin which resources you find most helpful
4. **Check new additions**: Admins may add resources over time
5. **Report broken links**: Let admin know if a link doesn't work

## 🆘 Troubleshooting

### Resource won't open

- Check your internet connection
- Try the link again
- Report to admin if consistently broken

### Can't see a resource

- Check if you're logged in
- Switch language to see if it appears
- Contact admin - it may be inactive

### Admin features not showing

- Verify you're logged in as admin
- Refresh the page
- Check user role in admin panel
