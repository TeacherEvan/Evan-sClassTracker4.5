## Important Notes

### Convex Generated Files

- `convex/_generated/api.d.ts` is auto-generated
- It's modified when you add new tables/functions
- It's safe to commit (tracks API changes)
- Gets regenerated on next `npx convex dev`

### Environment Files

- `.env.local` should NOT be committed (already in .gitignore)
- Verify it's not in staged files

### Large Files

- No large files added
- All files are source code

1. **Test Deployment** (if using Vercel/production):
   - Verify automatic deployment triggered
   - Test in production environment
   - Check Convex backend sync

2. **User Acceptance Testing**:
   - Login as admin
   - Initialize default resources
   - Test CRUD operations
   - Login as teacher
   - Verify resource display
   - Test language switching

3. **Monitor**:
   - Check for any production errors
   - Monitor Convex dashboard
   - Review user feedback

## Rollback Plan (if needed)

If issues occur:

```powershell
# Revert last commit
git revert HEAD

# Or reset to previous commit
git reset --hard HEAD~1

# Force push (use with caution)
git push origin main --force
```
